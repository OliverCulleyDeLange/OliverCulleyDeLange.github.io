A deliberately simple place to explore the world. It uses OpenFreeMap's vector tiles and MapLibre GL JS, so there is no API key, sign-up, or proprietary map SDK involved.

Try a different base-map style, jump to your location, or just pan and zoom. The coordinate readout is there because maps are more fun when they feel a little bit like instruments.
