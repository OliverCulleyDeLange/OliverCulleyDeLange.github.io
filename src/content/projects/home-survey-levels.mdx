Every conveyancer's website has the same table comparing RICS Level 2 and Level 3 home surveys, and none of them tell you what you're actually paying for.

This one shows you. It's a Level 2 report for a fictional 1890s terrace, with the extra detail a Level 3 report could add highlighted in green, section by section: how the house is built, what's wrong, why, what to do about it and, as an optional extra, roughly what it costs. Then a short set of questions about the house you're buying points you towards the level to discuss with a surveyor.

Built as a single Astro page with vanilla TypeScript. No framework, no dependencies, no network calls.
